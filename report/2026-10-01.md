# Daily report — 1 October 2026

## What shipped

Added a ChatGPT Chat Export tool that mirrors the existing Claude Chat Export: paste a public `chatgpt.com/share` link and download the conversation as Markdown, TXT, DOCX, or PDF. ChatGPT exposes no anonymous JSON API for shares (`backend-api/*` returns 403), so the reader fetches the share route's React Router v7 "single fetch" endpoint (`/share/<id>.data`) and decodes the turbo-stream locally. The Markdown/TXT/DOCX/PDF writers were extracted into a shared, provider-agnostic module so Claude and ChatGPT now export through one code path.

## Changes

- New `lib/chatgpt.ts`: share-id parsing, memoized turbo-stream decoder, share fetch with backoff retry, message extraction (visible user/assistant text only), and `DocChat` mapping.
